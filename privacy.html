Политика конфиденциальности Pulse

Редакция от 19 ноября 2026 года

Политика описывает текущую опубликованную версию Pulse, поддерживаемую владельцем репозитория Rockky666/pulse-channel-monitor. Она относится к Pulse, а не к сайтам социальных платформ.

Какие данные используются

Пользователь вводит названия групп, ссылки на каналы и видео, метрики, даты, названия и адреса превью. Эти сведения нужны для отображения групп, сводных показателей и публикаций. При подключении бэкенда используются также адрес Cloudflare Worker и отдельный код доступа Pulse.

Хранение на устройстве

Группы, публикации, показатели и адрес Worker сохраняются в localStorage браузера до удаления пользователем или очистки данных сайта. Экспорт создает JSON-файл на устройстве. Импорт читает выбранный пользователем файл в браузере. Код доступа Pulse хранится только в памяти текущей вкладки и не включается в экспорт групп; после перезагрузки его нужно ввести снова. Общей серверной базы групп и синхронизации между устройствами в текущем коде нет.

Запросы к YouTube и вашему бэкенду

При нажатии «Обновить YouTube» браузер передает ссылку на выбранный канал и код доступа Pulse на адрес Worker из настроек. Указывайте только адрес собственного доверенного бэкенда. Worker обращается к YouTube Data API и возвращает публичные метрики и сведения о роликах, которые затем сохраняются в браузере.

Пользователь настраивает ключ YouTube API как секрет в своем аккаунте Cloudflare, а не в клиентском коде. Предоставленный в репозитории Worker не записывает группы и ответы API в базу данных. Cloudflare и Google могут обрабатывать технические данные запросов по своим правилам. Настройки и журналы пользовательского Worker находятся под управлением его владельца.

Подключение TikTok

При нажатии «Подключить TikTok» сервис открывает окно авторизации TikTok. Пароль вводится только на стороне TikTok. По вашему разрешению Worker получает идентификатор и имя профиля, ссылку на профиль, доступные счетчики подписчиков и лайков, список публичных видео, их превью, даты и показатели. Эти сведения используются для отображения выбранной вами группы. Instagram по-прежнему заполняется вручную; его авторизация не реализована.

Client secret TikTok хранится в секретах вашего Cloudflare Worker. Access token и refresh token TikTok, их сроки действия, разрешения, идентификатор и сведения подключенного профиля сохраняются в приватном SQLite-backed Durable Object TIKTOK_STORE в вашем Cloudflare-аккаунте. OAuth-токены не возвращаются браузеру и не включаются в экспорт. В браузере сохраняются метрики и идентификатор подключения, для использования которого дополнительно нужен код доступа Pulse. Владелец такого кода может обращаться ко всем аккаунтам, подключенным к его личному Worker; конфигурация не предназначена для пользователей с раздельными правами под одним общим кодом.

При обновлении роликов Worker обращается к TikTok API, при необходимости обновляет и заменяет токены. Группы и история показателей остаются в браузере, а не в серверной базе групп. Для завершения авторизации создается одноразовая сессия сроком до 10 минут; истекшие сессии очищаются сервером. Доступ можно отозвать кнопкой «Отключить» в карточке TikTok или в настройках самого TikTok. После успешного отзыва Worker удаляет запись токенов. При истечении срока refresh token сервер очищает секреты, но может сохранять неполную запись идентификатора подключения и имени до удаления или повторной авторизации.

Cloudflare и TikTok обрабатывают технические данные запросов по своим правилам. Восстановление и резервное хранение данных у поставщика хостинга регулируются его политиками. Текущая реализация предназначена для настройки и тестирования через ваш TikTok Sandbox; она не означает, что приложение одобрено TikTok для production.

Внешние ресурсы

Сайт размещен на GitHub Pages. При его открытии GitHub получает технические данные соединения, включая IP-адрес, согласно своей политике конфиденциальности. Для шрифта сайт обращается к Google Fonts, для демонстрационных изображений — к Unsplash. Эти поставщики получают технические данные сетевых запросов. Добавленные пользователем изображения также загружаются из соответствующих внешних источников.

При открытии ролика пользователь переходит на стороннюю площадку, где действуют ее правила обработки данных. Текущий код Pulse не подключает собственные рекламные трекеры или сервисы веб-аналитики и не продает данные групп.

Удаление и контроль

Можно удалить отдельное видео или группу в интерфейсе, удалить демонстрационные данные в настройках, экспортировать копию или полностью очистить данные сайта в браузере. Экспортированные файлы удаляются отдельно на устройстве. Отключение бэкенда удаляет сохраненный адрес Worker и код из памяти вкладки, но не удаляет Worker и его секреты в Cloudflare и не отзывает TikTok-разрешения. Для отзыва используйте кнопку отключения TikTok-аккаунта. Ротация и удаление этих секретов выполняются в аккаунте Cloudflare.

Связь и изменения

Для вопросов используйте обращение в репозитории Pulse на GitHub. Обращение публичное: не указывайте пароли, токены и личные сведения. Если вопрос содержит конфиденциальную информацию, сначала запросите отдельный канал связи, не публикуя сами данные. При изменении способа обработки политика обновляется; дата редакции указана выше.
